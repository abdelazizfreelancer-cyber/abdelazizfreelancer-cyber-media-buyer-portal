# Media Buyer Portal 🚀

بوابة ونظام متكامل لإدارة عملاء الميديا باينج (Media Buying Client Portal).

## المميزات
- **إدارة العملاء والبريف (Client Brief)**: نموذج تفاعلي ذكي خطوة بخطوة (Wizard Form) لجمع كل تفاصيل البراند والنشاط الإعلاني.
- **حجز مواعيد الميتينج (Meeting Scheduler)**: حجز المواعيد حسب الأيام والساعات المتاحة مع عد تنازلي وتنبيهات صوتية ورابط الاجتماع قبل الموعد بـ 10 دقائق.
- **العقد الإلكتروني (Digital Contract)**: عرض بنود العقد وتوقيعه إلكترونياً مع إمكانية الطباعة والحفظ كـ PDF.
- **لوحة تحكم كاملة للإدارة (Admin Dashboard)**:
  - إحصائيات سريعة للعملاء والبريفات والميتينجات والعقود.
  - إضافة وتعديل أسئلة البريف ومواعيد الميتينج وبنود العقد.
  - تصدير بيانات العملاء إلى ملف Excel / CSV.
  - تواصل مباشر عبر واتساب بنقرة واحدة.

## التشغيل
المشروع يعمل مباشرة عبر المتصفح (Static HTML/CSS/JavaScript)، ولا يتطلب خادم أو إعدادات معقدة.
جاهز للرفع على **Vercel** أو **GitHub Pages**.
